# FX初心者向け学習ブログ　見本（モック）サイト

**見本（モック）・非公開**です。完成イメージを確認するためだけの、静的HTMLの試作です。

## 開き方

- **iPhoneのFilesから直接開いてもデザインが効く（CSS/JSは各HTMLに埋め込み）**。HTMLファイル1つだけを開いても、見た目とメニュー開閉が動きます（画像・Webフォントなどの外部ファイルは使っていません）。

**方法1：ファイルを直接開く（いちばん簡単）**
`/workspace/fx-blog-mock/index.html` をブラウザで開いてください（`file:///workspace/fx-blog-mock/index.html`）。

**方法2：ローカルサーバーで開く**
```bash
cd /workspace/fx-blog-mock
python3 -m http.server 8765
```
ブラウザで http://127.0.0.1:8765/ を開きます。終わったら `Ctrl + C` で止めます（自分のPCの中だけで動き、インターネットには公開されません）。

- 記事は `/workspace/articles/reviewed/`（編集長レビュー済み）の A-00・A-02・A-03 をそのまま変換しています。
- ［図解：〜］の指示は「図解（準備中）」の点線枠で表示しています。
- まだない記事（A-01、A-04〜、B〜D）へのリンクは「（準備中）」と表示し、リンクにしていません。
- **A-01 の原稿はまだ届いていない**ため、入門カテゴリでは「原稿未着」と表示しています。
- 予定の28本（A-00＋入門7・基礎7・実践7・応用6）をカテゴリページに並べています。タイトルはA-00原稿に書かれているものを使い、書かれていないものは「タイトル未定」としています。
- 記事ページには、パンくずリスト、「いま学んでいるステップ」の表示、目次、前後の記事への移動があります。
- **スマホ対応（レスポンシブ）**：全13ページに viewport 設定あり。幅760px以下ではメニューが「≡ メニュー」ボタンで開閉（`aria-expanded` 付き、Escキーで閉じる）、PCでは従来どおり横並びです。記事の表・長いURL・コードは画面からはみ出さず、文字は16px・行間1.75、ボタンやメニューは押しやすい高さ（約44px）にしています。幅360px／390px／1280pxで全ページの横はみ出しがないことを確認済みです。
- 見た目は `assets/style.css`、メニュー開閉は `assets/nav.js`、ページの共通部分は `_build/build.py` にあります（作り直しても消えません）。`assets/` は編集用の元データで、ビルド時に中身が各HTMLの `<style>`／`<script>` に埋め込まれます。表示のときに `assets/` は読み込みません。CSSやJSを直したら、下の「作り直すとき」のコマンドで再ビルドしてください。
- `shots/` は確認用のスクリーンショットで、ページからは参照していません。
- サイト名「はじめてのFX学習ノート」は仮の名前です。

## やっていないこと

- サーバー・ドメインの契約や取得、テーマの購入など、**お金がかかることは何もしていません**。
- インターネットへの**公開はしていません**（全ページに `noindex` を設定）。
- **広告・アフィリエイト（ASP）リンク・PRボタン・口座開設ボタンは入れていません**。A8.netなどへの登録や申請もしていません。
- お問い合わせフォームは見た目だけで、送信できません。
- 必須ページの本文は仮の文です。公開前に正式な内容を作る必要があります。
